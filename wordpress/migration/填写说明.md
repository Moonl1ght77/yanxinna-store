# 产品批量导入 · 填写说明

一行 = 一个产品。填完把 CSV 和图片文件夹发给 AI，AI 生成俄/英美/英英/法/德五语文案并用 WP-CLI 导入。

**用 Excel 打开会正常显示中文**（文件带 BOM）。改完记得另存为 CSV UTF-8。

## 列说明

| 列 | 必填 | 怎么填 | 例子 |
|---|---|---|---|
| 产品编号 | ✅ | 全站唯一，别和已有的重复 | `YX-006` |
| 中文名 | ✅ | 中文即可，AI 翻五语；网址会自动生成英文短横线 | `高腰塑身裤` |
| 大类 | ✅ | 英文，已有的是 `Shapewear` | `Shapewear` |
| 子类 | ✅ | 英文，没有的 AI 会新建 | `Bottoms` |
| 尺码 | ✅ | 逗号分隔，**整个用双引号包起来** | `"S,M,L,XL"` |
| 颜色 | ✅ | `中文色名 #色值`，多色用 `|` 分隔 | `黑色 #1a1a1a\|肤色 #d9b8a0` |
| 面料 | ✅ | 中文，成分要真实 | `"85% 尼龙, 15% 氨纶"` |
| 洗护 | | 留空用默认「冷水手洗 平铺晾干」 | |
| 压缩等级 | | `Light` / `Medium` / `Firm`，留空按 `Medium` | `Firm` |
| 卖点 | | 中文，`|` 分隔，3–4 条；留空 AI 按品类生成 | `高腰收腹\|无痕裤口` |
| 首页推荐 | | `是` / `否`，留空按否 | `是` |
| 热销 | | `是` / `否`，留空按否 | `否` |
| 排序 | | 数字，越小越靠前，留空按 0 | `6` |
| 图片文件夹 | ✅ | 本机绝对路径，一个产品一个文件夹 | `E:\Studio-Assets\YANXINNA\YX-006` |

**含逗号的格子必须用双引号包起来**（尺码、面料），否则 CSV 会被拆错列。

## 图片命名规则

图片放在「图片文件夹」里，按颜色命名，AI 自动配对：

```
黑色白底.png       ← 主图（列表首图）
黑色模特正面.png    ← 悬停图（鼠标放上去换的那张）
肤色白底.png       ← 第二个颜色的主图
肤色模特正面.png
细节-面料.png      ← 其余文件自动进详情页图集
细节-裤口.png
```

规则：
- 文件名含 **`白底`** → 该颜色的主图
- 文件名含 **`模特`** → 该颜色的悬停图
- 其余文件 → 全部进图集，按文件名排序
- **第一个颜色的白底图 = 产品主图**

## 图片要求

上传前先压：**转 WebP 或 JPG、宽度 1200 以内、目标 200–300KB**。

现在站上是原图直出，一张 1.4MB。俄罗斯客户手机打开首页会明显卡。这一条是整站最大的性能短板。

## 交付方式

1. CSV 填完
2. 图片文件夹按上面规则整理好
3. 一起发给 AI

AI 会：生成五语文案 → 图片传服务器 → 命令行导入 → 验证进 API → 报结果。

**导进去的是发布状态，前台立刻可见**（约 1 分钟缓存传播）。文案是机器翻译水平，俄语正式推广前建议找母语者复核。
