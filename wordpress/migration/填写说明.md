# 产品批量导入 · 填写说明

一行 = 一个产品。CSV 填完、图片放好，跑一条命令：脚本调 Claude 生成俄/英美/英英/法/德五语文案，压图，传到服务器，用 WP-CLI 导入并核验。命令见最后「交付方式」。

**用 Excel 打开会正常显示中文**（文件带 BOM）。改完记得另存为 CSV UTF-8。

## 列说明

| 列 | 必填 | 怎么填 | 例子 |
|---|---|---|---|
| 产品编号 | ✅ | 全站唯一，别和已有的重复 | `YX-006` |
| 中文名 | ✅ | 中文即可，AI 翻五语；网址会自动生成英文短横线 | `高腰塑身裤` |
| 大类 | ✅ | 英文，已有的是 `Shapewear` | `Shapewear` |
| 子类 | ✅ | 英文，没有的 AI 会新建 | `Bottoms` |
| 尺码 | ✅ | 逗号分隔，**整个用双引号包起来** | `"S,M,L,XL"` |
| 颜色 | ✅ | `中文色名 #色值`，多色用 `|` 分隔 | `黑色 #1a1a1a\|肤色 #d9b8a0` |
| 面料 | ✅ | 中文，成分要真实 | `"85% 尼龙, 15% 氨纶"` |
| 洗护 | | 留空用默认「冷水手洗 平铺晾干」 | |
| 压缩等级 | | `Light` / `Medium` / `Firm`，留空按 `Medium` | `Firm` |
| 卖点 | | 中文，`|` 分隔，3–4 条；留空 AI 按品类生成 | `高腰收腹\|无痕裤口` |
| 首页推荐 | | `是` / `否`，留空按否 | `是` |
| 热销 | | `是` / `否`，留空按否 | `否` |
| 排序 | | 数字，越小越靠前，留空按 0 | `6` |
| 图片文件夹 | ✅ | 一个产品一个文件夹。后台批量导入填压缩包里的文件夹名；电脑上跑脚本填绝对路径 | `YX-006` 或 `E:\Studio-Assets\YANXINNA\YX-006` |

**含逗号的格子必须用双引号包起来**（尺码、面料），否则 CSV 会被拆错列。

## 图片命名规则

图片放在「图片文件夹」里，按颜色命名，脚本自动配对：

```
黑色白底.png       ← 主图（列表首图）
黑色模特正面.png    ← 悬停图（鼠标放上去换的那张）
肤色白底.png       ← 第二个颜色的主图
肤色模特正面.png
细节-面料.png      ← 其余文件自动进详情页图集
细节-裤口.png
```

规则：
- 文件名含 **`白底`** → 该颜色的主图
- 文件名含 **`模特`** → 该颜色的悬停图
- 其余文件 → 全部进图集，按文件名排序
- **第一个颜色的白底图 = 产品主图**

## 图片要求

原图随便多大都行，脚本会统一压成 1200×1600 的 JPG（3:4、浅灰底，和站上既有产品图一致，一张 60–150KB）。每个颜色必须有白底图和模特图各一张，缺一张就报错停下。

## 交付方式

三条路写进去的数据一模一样，按手边有什么选：

**① 后台批量导入（商家用，不需要电脑上装任何东西）**：WordPress 后台「产品 → 批量导入」，上传这张 CSV 和一个图片 ZIP（压缩包里一个产品一个文件夹，文件夹名填在「图片文件夹」列）。页面会一个产品一个产品地生成五语、压图、入库，完成后给出后台编辑和网站链接。失败的可以点「重试失败的产品」。

**② 后台单个产品（商家零星加一两个）**：新建产品，填最上面「中文原文」那组和每个颜色的「中文色名」，传好图、勾好尺码分类，点「用中文生成五种语言文案」，30–60 秒后五语字段填满，检查后发布。

以上两条都要管理员先在「设置 → Connectors」装一个 AI 供应商（推荐 Anthropic）并填 API key，按量付费，一个产品几分钱。

**③ 电脑上跑脚本（Joe 批量用）**：在项目目录（`.worktrees/headless-wordpress-cms`）跑：

```bash
npm run import:products -- "E:\路径\产品.csv"
```

脚本会：读 CSV → 逐个产品调 Claude 写五语文案 → 压图 → 上传服务器 → WP-CLI 导入 → 请求线上 API 核验 → 打印每个产品的网址。

**默认导入即发布，前台约 1 分钟后可见**。想先看一眼再发，加 `--draft`，脚本会打印后台编辑链接。只想生成不上传，加 `--stage-only`；之后用 `--push <目录>` 再传。同一产品编号重复跑是更新，不会重复建产品、重复传图。

一次性准备（每台电脑一次）：
- 翻译走本机的 Claude Code 命令行，没登录过就在终端跑 `claude login`（或设置 `ANTHROPIC_API_KEY`）。
- 服务器用公司机的 SSH 私钥 `~/.ssh/yanxinna_cms`，没有这把钥匙的电脑传不上去。

文案是机器翻译水平，俄语正式推广前建议找母语者复核。
